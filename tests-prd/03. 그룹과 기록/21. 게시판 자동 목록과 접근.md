# 21. 게시판 자동 목록과 접근

> E2E: `tests/03. 그룹과 기록/21. 게시판 자동 목록과 접근/`

1. 게시판 API는 조회만 지원하며 역할 파라미터로 쓰기 기능을 사용할 수 없다.

2. 게시판 Notes는 Note·To Do·Ready·Doing·Done 다섯 상태의 본문이 있는 모든 카드를 합산한다. 닫힌 탭과 짧은 본문도 포함하고 빈 본문은 제외한다. 집계 조회는 기존 탭이나 그룹을 변경하지 않는다.

3. 상세 notes 응답에는 편집기 열림 여부와 관계없이 기존 본문 표시 기준을 충족하는 모든 상태의 노트를 포함하고 dashboardStatus·tabColor를 제공한다. 이 조회는 기존 그룹·탭을 수정하지 않는다.

4. 게시판은 현재 공유 그룹에 참여한 사용자에게만 그룹과 노트 본문을 반환한다. 초대 수락 후 접근을 허용하고 나가면 다시 제외한다. 조회 응답은 캐시하지 않는다.
