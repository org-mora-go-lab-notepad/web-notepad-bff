# 18. 공유 그룹과 알림

> E2E: `tests/03. 그룹과 기록/18. 공유 그룹과 알림/`

1. 삭제 확인이 없는 오래된 저장 요청은 서버의 공유 탭을 지우지 못한다. 구버전이 `deletedTabIds`만 보내도 거부하며, 영구 제거는 별도의 `confirmedDeletion: true`와 대상 ID를 함께 전달해야 한다. 누락 거부 응답에는 최신 데이터를 포함하고 현재 수정 본문은 보존한다.
2. 공유 탭은 본문 길이와 관계없이 빈 내용과 1~2자 내용도 서버에 보존하고, 명시적 삭제 의도가 없으면 자동 삭제하지 않는다.
