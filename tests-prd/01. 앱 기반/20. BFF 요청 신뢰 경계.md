# 20. BFF 요청 신뢰 경계

> E2E: `tests/01. 앱 기반/20. BFF 요청 신뢰 경계/`

1. 서명 없는 직접 요청은 사용자 쿠키가 있어도 거부한다.
2. 서명 컨텍스트를 변조하면 요청을 거부한다.
3. 만료된 서버 서명 요청을 거부한다.
4. 다른 경로에 발급한 서명을 재사용할 수 없다.
5. 다른 HTTP 메서드에 발급한 서명을 재사용할 수 없다.
6. 서명 이후 변경된 본문을 저장하지 않는다.
7. BFF는 카카오 OAuth 엔드포인트를 제공하지 않는다.
8. 서명된 익명 요청에 사용자 헤더를 추가해도 개인 이력을 볼 수 없다.
9. 원본 공유 토큰만으로는 프런트 검증 증명 없이 BFF에 참여할 수 없다.
10. BFF는 기존 인증 키 없이 공유 링크 서명에 필요한 ID와 버전만 반환하며 본문과 사용자 데이터는 보존한다.
